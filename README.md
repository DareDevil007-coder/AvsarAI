# AvsarAI
Portal for Academia - Industry collaboration for Skill Mapping, Internships and Placement
AI-Based Internship Recommendation Engine for PM Internship Scheme

1. WEBSITE TOPIC

Build an MVP named:

PM Internship Recommendation Engine

The system uses AI to recommend the most suitable PM Internship opportunities to students based on their skills, education, interests, preferences, eligibility, and location.

2. MVP FEATURES

Student:
- Register/Login
- Create profile
- Add education
- Add skills
- Add interests
- Select preferred domains
- Select preferred locations
- View eligibility
- Get AI internship recommendations
